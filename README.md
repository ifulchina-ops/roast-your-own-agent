One funny line roasting my own AI agent: it never says "I don't know" — it invents a library, imports it, and lets me discover the function doesn't exist. The joke is specific to how an agent actually behaves: the confident wrong answer, delivered as working code, with the human left to find the hole.

## Run it

```sh
node main.ts
```

This writes the roast to `/output/entry.txt` (118 characters, inside the 1–200 gate).
